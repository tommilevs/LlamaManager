# Localization

LlamaManager uses **English as the source locale** and ships Russian as the first built-in translation.

Core catalog files live under:

```text
src/llamamanager/locales/en.json
src/llamamanager/locales/ru.json
```

Missing keys fall back to English.

## Web locale selection

The Web UI exposes a language selector and persists the selected locale in a `llamamanager_locale` cookie. Changing the UI language does not rewrite machine configuration.

## Localization metadata

Supported locale metadata is stored separately under:

```text
src/llamamanager/locales/metadata/
```

with native display names for each known locale.

## Temporary MCP Developer Mode

Normal MCP sessions do not expose localization editing tools. An administrator can temporarily enable the localization developer group:

```bash
llamarun mcp developer enable --for 1h --group localization
```

Developer Mode is local to the machine and time-limited. It does not bypass read-only/full-control policy.

When enabled, MCP exposes:

- `get_supported_locales`
- `get_translation_catalog`
- `list_missing_translation_keys`
- `upsert_translation_entries`

`upsert_translation_entries` performs an atomic JSON rewrite and requires `full-control` access. MCP must already be enabled for the live-process policy acknowledgement to succeed; otherwise the CLI refuses to save an unacknowledged capability expansion.

Disable it explicitly when finished:

```bash
llamarun mcp developer disable
```
